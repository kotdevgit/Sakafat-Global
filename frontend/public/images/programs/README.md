# Programmes page assets

Add assets for the Programmes page to these section folders:

- `hero/`: studio background photo. Suggested filename: `studio-background.webp` (JPG or PNG also accepted). Export the full-resolution photo without the heading, button, or dark overlay; those will be built in the page.
- `discovery/`: optional SVG icons for All Programmes, Open Now, Upcoming, and In Development. Suggested names: `all-programmes.svg`, `open-now.svg`, `upcoming.svg`, `in-development.svg`. The six card banners are text and gradients, so they do not need image exports.
- `participation/`: any additional artwork for the participation steps. The supplied mockup needs no images here; numbers, cards, and text will be built in the page.
- `status-note/`: any additional artwork for the status notice. The supplied mockup needs no images here; the gradient, border, text, and button will be built in the page.

The existing `mic-icon.svg` is used by the homepage programs section. Shared header/footer assets stay in their current folders and will be reused.

Use SVG for icons and WebP/JPG for photos. Keep text and buttons separate from exported images. Other descriptive filenames are fine.
